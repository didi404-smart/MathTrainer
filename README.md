# MathTrainer

## Описание

MathTrainer — десктоп‑приложение на Python (PySide6) для тренировки базовой математики у детей (садик и начальная школа).
Примеры генерируются бесконечно с помощью `random`. Можно тренироваться без ограничений или пройти тест с выбранным количеством вопросов.

## Возможности

- **Пять тем:** сложение, вычитание, умножение, деление, уравнения
- **Выбор уровня сложности** в каждой теме
- **Два режима:** «Подготовка» и «Тест»
- Бесконечная генерация примеров
- Управление с клавиатуры: Enter проверяет ответ, а затем переходит к следующему примеру
- Тесты на `pytest` (случайность подменяется через `unittest.mock`)

## Как пользоваться

Навигация по приложению:

```
Главное меню → тема → уровень → режим (Подготовка / Тест)
```

У уравнений между темой и режимом есть дополнительный шаг: сначала выбирается тип уравнений, затем предел чисел.

### Режим «Подготовка»

Свободная тренировка без ограничений:
- при неверном ответе поле ввода подсвечивается красным, ответ можно вводить снова
- после первой ошибки появляются кнопки **«Показать ответ»** и **«Следующий пример»**
- при правильном ответе поле подсвечивается зелёным и появляется кнопка **«Следующий пример»**
- примеры идут, пока вы не нажмёте «Назад»

### Режим «Тест»

Проверка знаний с ограниченным числом вопросов:
- перед началом приложение спрашивает, сколько вопросов будет в тесте (от 1 до 100, по умолчанию 10)
- на каждый вопрос даётся **одна попытка**: после нажатия «Ответить» поле блокируется
- если ответ неверный, поле подсвечивается красным и показывается правильный ответ
- сверху виден прогресс: «Вопрос 3 из 10»
- на последнем вопросе кнопка меняется на «Завершить тест»
- в конце показывается результат: количество правильных ответов и процент
- с экрана результата можно **«Пройти ещё раз»** (тот же уровень и число вопросов) или вернуться **«К выбору режима»**

Пустой ответ не засчитывается и не тратит попытку. Кнопка «← Назад» во время теста прерывает его без сохранения результата.

## Уровни

### Сложение / Вычитание
- до 20
- до 50
- до 100
- до 1000
- до 100000
- до 1000000000

### Умножение
- таблица умножения (10×10)
- умножение на однозначное число
- умножение на двузначное число
- умножение на трёхзначное число
- умножение на четырёхзначное число
- все вместе

### Деление (без остатка)
- таблица деления (10×10)
- деление на однозначное число
- деление на двузначное число
- деление на трёхзначное число
- все вместе

### Уравнения
Сначала выбирается тип уравнений, затем предел чисел:

| Тип | Примеры | Пределы |
|---|---|---|
| Сложение и вычитание | `x + a = b`, `a - x = b`, `x + a - b = c` | до 100, до 1000, случайно |
| Умножение и деление | `a × x = b`, `x ÷ a = b`, `a ÷ x = b` | до 100 (таблица умножения), до 1000, случайно |
| Смешанные | `x × m + k = r`, `x × m - k = r` | до 100, до 1000, случайно |

Режим «случайно» выбирает предел (100 или 1000) для каждого примера отдельно.
Все числа в уравнении, включая промежуточные результаты, не превышают выбранный предел.
Ответ всегда целый и неотрицательный и определяется однозначно (например, уравнения вида `0 × x = 0` не генерируются).

## Установка

Проект разрабатывался на Python 3.14.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/<your-username>/MathTrainer.git
cd MathTrainer
```
2. Установите [poetry](https://python-poetry.org/docs/#installation), если его ещё нет:
```bash
pip install poetry
```
3. Установите зависимости:
```bash
poetry install
```

## Запуск

```bash
poetry run python -m src.MathTrainer.ui.app
```

## Тесты

```bash
poetry run pytest
```

С отчётом о покрытии, включая ветвления:
```bash
poetry run pytest --cov=src.MathTrainer --cov-branch --cov-report=term-missing
```

Тесты покрывают генераторы задач. Во всех тестах `random.randint` и `random.choice` подменяются фикстурами из `tests/conftest.py`: числа задаются вручную через `side_effect`, поэтому результат каждого теста детерминирован и не зависит от случайности.

Пример теста:
```python
def test_multiplication_one_digit(randint):
    randint.side_effect = [100, 9]

    assert multiplication_one_digit() == Task(text="Выполни умножение(столбиком) 100 × 9 = ?", answer=900)
```

## Структура проекта

```bash
src/MathTrainer/
  core/
    task.py                   # модель задачи (Task)
  generators/
    addition.py               # генератор задач (сложение)
    subtraction.py            # генератор задач (вычитание)
    multiplication.py         # генераторы задач (умножение)
    division.py               # генераторы задач (деление)
    equations.py              # генераторы уравнений (параметр limit)
  ui/
    app.py                    # GUI: меню, выбор уровня и режима, подготовка, тест

tests/
  conftest.py                 # фикстуры randint и choice (подмена random)
  test_addition.py
  test_subtraction.py
  test_multiplication.py
  test_division.py
  test_equations.py
```

### Устройство интерфейса (`ui/app.py`)

| Класс | Назначение |
|---|---|
| `MainMenuPage` | главное меню со списком тем |
| `VariantsPage` | выбор уровня; умеет открывать вложенное подменю (уравнения) |
| `ModePage` | выбор режима: подготовка или тест |
| `TrainerPage` | режим «Подготовка» |
| `QuizPage` | режим «Тест» |
| `QuizResultPage` | итоги теста |
| `App` | главное окно, навигация между страницами |

Чтобы добавить новую тему, достаточно написать функцию `make_variants_...`, которая возвращает список пар `(название, генератор)`, и добавить её в словарь `TOPICS`. Кнопка в главном меню появится автоматически, а выбор режима подключится сам.
