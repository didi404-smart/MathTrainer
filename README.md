# MathTrainer

## Описание:

MathTrainer — учебный проект: десктоп‑приложение на Python для тренировки базовой математики у детей (садик/начальная школа).  
Приложение генерирует бесконечное количество примеров с помощью `random`.

На текущий момент реализован раздел **Подготовка → Сложение** с выбором уровней.

## Возможности:

### Сейчас реализовано:
- Раздел **Подготовка**
- Темы:
  - **Сложение**
  - **Вычитание**
- Выбор уровней для каждой темы:
  - до 20
  - до 50
  - до 100
  - до 1000
  - до 100000
  - до 1000000000
- Бесконечная генерация примеров
- Поведение тренажёра:
  - при неверном ответе поле ввода подсвечивается красным
  - после первой ошибки появляются кнопки **«Показать ответ»** и **«Следующая задача»**
  - кнопка **«Показать ответ»** выводит правильный ответ
  - при правильном ответе поле ввода подсвечивается зелёным и появляется кнопка **«Следующая задача»**
- Тесты логики на `pytest`

## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/<your-username>/MathTrainer.git
```
2. Установите poetry:
```bash
poetry install
```
3. Установите зависимости:
```bash
poetry install
```

## Документация:
Структура проекта:
```bash
src/MathTrainer/
  core/
    task.py                   # модель задачи (Task)
  generators/
    addition.py               # генератор задач (сложение)
    subtraction.py            # генератор задач (вычитание)
  ui/
    app.py                    # GUI: главное меню, уровни, тренажёр

tests/
  test_addition.py            # тесты генератора сложения
  test_subtraction.py         # тесты генератора вычитания
```
