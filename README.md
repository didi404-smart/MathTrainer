# MathTrainer

## Описание

MathTrainer — учебный проект: десктоп‑приложение на Python (PySide6) для тренировки базовой математики у детей (садик/начальная школа).
Приложение генерирует бесконечное количество примеров с помощью `random`.

## Возможности

### Сейчас реализовано
- Раздел **Подготовка**
- Темы:
  - **Сложение**
  - **Вычитание**
  - **Умножение**
  - **Деление**
  - **Уравнения**
- Бесконечная генерация примеров
- Поведение тренажёра:
  - при неверном ответе поле ввода подсвечивается красным
  - после первой ошибки появляются кнопки **«Показать ответ»** и **«Следующий пример»**
  - кнопка **«Показать ответ»** выводит правильный ответ
  - при правильном ответе поле ввода подсвечивается зелёным и появляется кнопка **«Следующий пример»**
  - Enter проверяет ответ, а после правильного ответа переходит к следующему примеру
- Тесты логики на `pytest` (случайность подменяется через `unittest.mock`)

### Уровни

#### Сложение / Вычитание
- до 20
- до 50
- до 100
- до 1000
- до 100000
- до 1000000000

#### Умножение
- таблица умножения (10×10)
- умножение на однозначное число
- умножение на двузначное число
- умножение на трехзначное число
- умножение на четырехзначное число
- все вместе

#### Деление 
- таблица деления (10×10)
- деление на однозначное число
- деление на двузначное число
- деление на трехзначное число
- все вместе

#### Уравнения
Сначала выбирается тип уравнений, затем предел чисел:

| Тип | Пределы |
|---|---|
| Сложение и вычитание (`x + a = b`, `a - x = b`, `x + a - b = c` и т. д.) | до 100, до 1000, случайно |
| Умножение и деление (`a × x = b`, `x ÷ a = b`, `a ÷ x = b`) | до 100 (таблица умножения), до 1000, случайно |
| Смешанные (`x × m + k = r`, `x × m - k = r`) | до 100, до 1000, случайно |

Режим «случайно» для каждого примера выбирает предел из 100 или 1000.
Все числа в уравнении, включая промежуточные результаты, не превышают выбранный предел, а ответ всегда целый и неотрицательный.

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/<your-username>/MathTrainer.git
cd MathTrainer
```
2. Установите [poetry](https://python-poetry.org/docs/#installation), если его ещё нет:
```bash
pip install poetry
```
3. Установите зависимости:
```bash
poetry install
```

## Запуск

```bash
poetry run python -m src.MathTrainer.ui.app
```

## Тесты

```bash
poetry run pytest
```

С отчётом о покрытии (включая ветвления):
```bash
poetry run pytest --cov=src.MathTrainer --cov-branch --cov-report=term-missing
```

Во всех тестах `random.randint` и `random.choice` подменяются фикстурами из `tests/conftest.py`,
поэтому результат каждого теста детерминирован.

## Документация

Структура проекта:
```bash
src/MathTrainer/
  core/
    task.py                   # модель задачи (Task)
  generators/
    addition.py               # генератор задач (сложение)
    subtraction.py            # генератор задач (вычитание)
    multiplication.py         # генераторы задач (умножение)
    division.py               # генераторы задач (деление)
    equations.py              # генераторы уравнений (с параметром limit)
  ui/
    app.py                    # GUI: главное меню, выбор режимов/уровней, тренажёр

tests/
  conftest.py                 # фикстуры randint и choice (подмена random)
  test_addition.py
  test_subtraction.py
  test_multiplication.py
  test_division.py
  test_equations.py
```
