# MathTrainer

## Описание:

MathTrainer — учебный проект: десктоп‑приложение на Python для тренировки базовой математики у детей (садик/начальная школа).  
Приложение генерирует бесконечное количество примеров с помощью `random`.

На текущий момент реализован раздел **Подготовка → Сложение** с выбором уровней.

## Возможности:

- Главное меню → выбор темы **Сложение**
- Выбор уровней:
  - сложение до 20
  - сложение до 50
  - сложение до 100
  - сложение до 1000
  - сложение до 100000
  - сложение до 1000000000
- Бесконечная генерация задач
- Логика тренажёра:
  - при неверном ответе поле ввода подсвечивается красным
  - после первой ошибки появляются кнопки **«Показать ответ»** и **«Следующая задача»**
  - **«Показать ответ»** выводит правильный ответ
  - при правильном ответе поле подсвечивается зелёным и появляется **«Следующая задача»**
- Тесты логики на `pytest`

## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/<your-username>/MathTrainer.git
```
2. Установите poetry:
```bash
poetry install
```
3. Установите зависимости:
```bash
poetry install
```

## Документация:
Структура проекта:
```bash
src/MathTrainer/
  core/
    task.py                   # модель задачи (Task)
  generators/
    addition.py               # генератор задач (сложение)
  ui/

tests/
  test_addition.py            # тесты генератора сложения
```
